# 常见问题（FAQ）

按场景归类的故障排查。找不到答案时，管理员可查 [审计日志](system-ops.md#审计日志)
确认最近发生过什么，再看根目录 `README.md` 的部署与配置章节。

## 登录相关

### 登录提示「账号或密码错误」，但密码肯定没错

- 密码哈希不是本机生成的（比如从别的机器拷了 `config.json`）：重新运行
  `python3 init_config.py` 覆盖生成（会自动备份旧配置）。
- 真忘了密码：同样用 `init_config.py` 重置管理员密码。

### 登录试了几次被锁了

连续失败达到上限（默认 5 次）会临时锁定（默认 300 秒），等一会儿再试；
确需调整阈值改 `config.json` 的 `login_max_fail` / `login_lock_seconds`。

### 想改密码

右上角账号菜单在线改密，会话不掉线；其他网站账号由管理员在
「设置 → 网站用户」里改。

## 检出相关（svn:// 协议）

### `svn checkout` 提示认证失败（Password incorrect）

多半是 `conf/passwd` 文件里有多余空格或格式问题。去用户管理页重新保存该账号
（会规范化写回），或直接检查仓库的 `conf/passwd`。

### 密码改了，检出还是用旧密码

svn 客户端有凭据缓存，清掉即可：

```bash
rm -rf ~/.subversion/auth
```

### 密码含 `*`、`(` 等特殊字符时检出失败

是客户端 / shell 转义问题：用单引号包裹，或把密码写进文件再读，避免手打漏字符。

### Web 能打开，但 `svn://` 检不出来

依次检查：

1. svnserve 在跑吗：`systemctl status svnserve`。
2. 端口在听吗：`ss -lntp | grep 3690`。
3. svnserve 的 `-r` 是否与 `config.json` 的 `repo_root` 一致。
4. 防火墙放行 3690 了吗。

### 网页里设的权限 / 账号对 https 检出不生效

你连的是 VisualSVN Server（Windows），它用自己的注册表账号库，
**不读** `conf/passwd` / `conf/authz`。两套体系互不相通，详见根目录
`README.md` 第七节补。本程序的管理功能面向 Linux + svnserve 场景。

## 浏览相关

### 新建的仓库网页上看不到

确认它建在 `config.json` 的 `repo_root` 之下（网页只扫描该目录下含 `db`
子目录的文件夹）。另外**已归档**的仓库不出现在列表，去「已归档仓库」页看。

### 大文件打不开 / 提示只可下载

超过预览上限（`max_preview_bytes`，默认 5MB）的文件只提供下载，属正常保护；
媒体文件的上限是 `max_media_bytes`（默认 32MB）。可在「站点设置」调大，
但注意内存与带宽压力。

### Markdown 渲染不完整

超长 Markdown 会截断渲染（默认 20 万字符），防页面卡死；完整内容用 raw / 下载。

## 搜索相关

### 搜索提示「结果可能不完整」

全历史代码搜索触发了扫描超时 / 超预算保护，是**如实提示**而非故障：
缓存命中后自动加速补全；也可由管理员调大 `search_scan_timeout`。

### 搜不到刚提交的内容

搜索范围与缓存都有 TTL（默认较短），稍等片刻或换个关键词重试；
版本列表本身没有缓存延迟。

## 管理相关

### 新建仓库报错 `'passwd' and 'passwd' are the same file`

旧版代码的历史 bug，已修复；如仍在旧版本，按 `changelog.md` 2026-09-29
条目打补丁。

### 创建分支后目标路径下多了一层子目录

创建前未检查目标是否已存在导致 `svn copy` 复制成子节点——当前版本会先检查
并明确报错；如遇到该现象说明在用旧版本，请升级。

### Windows 上管理功能各种不对劲（服务重启拒绝访问、hook 不生效…）

Windows 本就不推荐用于管理：服务管理需要管理员权限、hook 需为 `.bat`、
归档的 `chmod 000` 保护失效等，详见根目录 `README.md` 第七节补。

## 其他

### 仓库名取不了（提示保留名）

仓库名直接作为顶层 URL 路径，`users` / `admin` / `recent` / `settings` /
`audit` / `server` / `static` / `login` / `healthz` 等保留名不可用，换个名字即可。

### URL 访问被 308 重定向到奇怪地址

多为手输路径大小写或结尾斜杠差异触发 Flask 的严格路由跳转，用导航/链接
进入即可，不要手拼 URL。
