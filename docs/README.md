## 这个工具是什么

SVN Web 是一个 GitHub 风格的 Subversion 网页浏览与管理工具：

- **浏览**：像逛 GitHub 一样浏览 SVN 仓库——目录树、语法高亮、Markdown 渲染、媒体预览、Blame。
- **追溯**：版本列表、任意两个版本的区间对比、提交历史全量搜索。
- **管理**：网页上完成建仓、账号、权限矩阵、hooks、备份、归档等日常管理，底层全部落在
  `conf/passwd` + `conf/authz` 文件上——文件即真相，不引入第三套体系。

## 角色说明

系统内置两类网站账号角色，并可自定义角色：

- **admin**：全部权限（浏览 + 管理）。
- **viewer**：只读，仅浏览与查看。
- 自定义角色：管理员可在「设置 → 角色权限」按 9 项细粒度权限自由勾选，详见
  [用户与角色](users-roles.md)。
